# nlohmann/json

**nlohmann/json** (also known as *JSON for Modern C++*) is a popular open-source, header-only library that simplifies working with JSON data in C++, providing intuitive syntax and seamless integration with C++'s Standard Template Library (STL).<br>

It's widely used for configuration files, REST API clients, and any C++ project that needs reliable, ergonomic JSON handling. The library is noted for its intuitive syntax, trivial integration, and serious testing.<br>
